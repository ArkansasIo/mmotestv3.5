# Eldoria UI Image Assets

Use this folder for visual assets that belong to the interface rather than the game world: panels, emblems, map markers, and section-specific decorations.

Keep each asset:

- Named for its view or UI purpose.
- Sized and compressed for its actual display use.
- Tested against the current light or dark surface where it appears.
- Accessible: meaningful images need alternative text; decorative images should not create redundant screen-reader output.

Do not rely on a filename alone to explain an asset's role. Add a short note here when a new group needs special rendering or responsive treatment.
